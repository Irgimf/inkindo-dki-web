# INKINDO DKI Web

**INKINDO DKI Web** adalah portal web resmi **DPP INKINDO DKI Jakarta** yang menyajikan profil organisasi, direktori badan usaha anggota terdaftar, berita & informasi, regulasi, serta informasi kemitraan.

## Ringkasan Konten

- **Beranda & Profil Organisasi**: Informasi umum mengenai visi, struktur, dan layanan DPP INKINDO DKI Jakarta.
- **Anggota Terdaftar**: Direktori badan usaha konsultan anggota INKINDO DKI Jakarta.
- **Berita, Publikasi & Regulasi**: Agenda kegiatan, rilis informasi, e-magazine, serta informasi regulasi terkait.
- **Mitra Kerja**: Informasi program kemitraan dan profil mitra kerja resmi.

## Teknologi

- PHP (Laravel)
- Vite & Tailwind CSS
